Logo & Wordmark

The magnetiz.ai wordmark is set in JetBrains Mono Bold at 20px (nav) or 28px (display). The ".ai" portion is always rendered in Steel Blue (#4A9ECE). The logo is text-only — no icon, no symbol.

Primary Variants

magnetiz.ai
On surface background
magnetiz.ai
On light background (exception use)

Specifications

PropertyValue

Nav size20px
Display size28px
Letter spacing-0.5px
CasingAll lowercase — always magnetiz.ai
Accent color#4A9ECE applied to ".ai" only
Minimum clear spaceEqual to the height of the letter "m" on all sides

Do

  • Always lowercase: magnetiz.ai
  • Keep ".ai" in Steel Blue on dark backgrounds
  • Use JetBrains Mono exclusively for the wordmark
  • Maintain minimum clear space around the logo

Don't

  • Capitalize: Magnetiz.AI, MAGNETIZ.AI
  • Change the accent color of ".ai"
  • Use a different typeface for the wordmark
  • Add drop shadows, outlines, or effects to the logo

08

Voice & Tone

Magnetiz.ai speaks like a senior engineer — precise, confident, and no-nonsense. We use technical language comfortably but never gatekeep. The tone is direct and outcome-focused.

Voice Attributes

AttributeDescription
TechnicalWe speak the language of engineering — evaluation frameworks, production deployment, edge cases, confidence scores.
Evidence-basedClaims are backed by data and specific outcomes. No vague promises or hype.
DirectShort sentences. Active voice. We say what we mean without hedging.
ConfidentWe stand behind our work. "If we can't show a clear path to ROI — you don't pay."

Writing Patterns

Headlines

We build AI agents that work in production

Short. Declarative. Outcome-focused. Use JetBrains Mono. Accent key words in Steel Blue.

Section Labels

// The Problem
// The Solution

Code-comment style prefixed with // in Sage Green. Always uppercase first letter.

Contrasts

Evidence-Based > Vibes-Based
Custom Agents > Generic Tools

Good value in white, bad value struck-through in coral. Creates immediate differentiation.

CTAs

magnetiz.ai $ start --ai-audit

Terminal-style command prompts for CTAs. The action feels like running code, not clicking a marketing button.

Write like this

  • "Production-ready in less than 30 days"
  • "We deploy automated testing infrastructure"
  • "95% of enterprises run AI pilots. Only 11% reach production."
  • "If we can't show a clear path to ROI — you don't pay."

Not like this

  • "Unlock the power of AI for your business"
  • "Our innovative solutions leverage cutting-edge technology"
  • "Transform your enterprise with next-gen AI capabilities"
  • "Schedule a free consultation to learn more"

Usage Guidelines

Quick reference for maintaining brand consistency across all touchpoints — website, presentations, social, and documentation.

Hierarchy of Elements

LayerColorUsage
Page background--bg-deep #0d1117Always the base layer
Card / Panel--bg-surface #161b22Cards, terminals, nav (scrolled)
Header / Status bar--bg-elevated #1c2333Terminal chrome, elevated UI
Tag background--bg-card #21262dSmall inline elements, tags

Color Usage Rules

ColorRoleWhere
Steel BluePrimary action, links, emphasisButtons, logo accent, hover states, section accents
CoralWarning, negation, contrastStat numbers, strikethrough text, error states
Sage GreenSuccess, active, labelsStatus indicators, section labels, tags, "ready" states
AmberCaution, attentionWarning icons, status messages
PurpleCode keywords onlySyntax highlighting in terminal blocks
CyanCode built-ins onlySyntax highlighting in terminal blocks
OrangeCode numbers onlySyntax highlighting in terminal blocks

Presentation Slides

Do

  • Use #0d1117 or #161b22 backgrounds
  • Set headings in JetBrains Mono Bold
  • Use the syntax color palette for data viz
  • Include terminal chrome for code/data blocks
  • Keep the grid dot pattern as a subtle texture

Don't

  • Use white or light backgrounds
  • Substitute Arial, Helvetica, or other fonts
  • Use gradients not defined in the palette
  • Add stock photography or generic AI imagery
  • Use rounded, bubbly, or "friendly" UI patterns
