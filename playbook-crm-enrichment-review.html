How it works

01Gate the spend

Enrich only records something downstream will use, capped per day. An enrichment nobody reads is a bill with no customer.

Records that miss the gate queue rather than burn. The queue drains on schedule, inside the cap.

02Research with citations

The agent works public sources and every claim carries where it came from. Unknown stays unknown, never guessed.

A cited claim can be audited in one click. An uncited claim is a rumor in a database.

03Date every fact

A title verified last week beats one scraped last year. Every fact carries its date, and stale evidence decays out instead of masquerading as current.

Watch for the field that is confidently wrong. Undated data does not age, it lies.

04Propose, never overwrite

Silent overwrites are how trust dies. The agent produces proposed changes. Old value, new value, source, side by side. The record itself has not moved yet.

05Review the changes

A person approves before the record changes. The approval takes seconds, because the preview did the work. Low-risk fields can graduate to auto-apply later, on clean passes, and consequential fields never do.

06Keep it reversible

Every applied change is logged with its prior state. One click restores it. An enrichment pipeline you cannot undo is a pipeline you will eventually fear.

07Evaluate on golden records

Pick five accounts you know cold and write down the truth about them. Run the agent against those golden records and score it before trusting it, then re-score whenever the prompt, the model, or the sources change.

The eval is the difference between an agent you tested once and an agent you can keep trusting.

An enrichment is a claim. The record should hold evidence.
