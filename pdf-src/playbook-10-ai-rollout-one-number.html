The method

How It Works

Seven steps in 30 days. The worksheets for every one of them ship as the markdown files in this kit.

01Name the one number the rollout is for

One number, one owner, written before launch. Pick the result the owner of the number already answers for, such as second meetings per week or time from inbound to first touch. Write exactly what counts and where it is read from, so two people get the same count.

Watch for a usage number in disguise. Logins, drafts generated and seats activated rise when people use the tool, whether the result moves or not.

02Measure four weeks before

Read the number the same way for the four weeks before launch. Keep the lowest and highest week, because the gap between them is how much the number swings with no tool at all.

03Write what counts as moved

The line sits past the baseline's swing, in the direction the number should go. Write the read date, launch plus 30 days, and a minimum count below which the read is too thin to decide. Both owners sign before launch.

Watch for a line inside the normal swing. A good week then reads as the tool working.

04Pick a comparison

A holdout is strongest. One team, segment or region works without the tool for the same 30 days. With only one team, compare it against its own baseline, and list anything else planned that could move the number, such as a campaign, hiring or a price change.

magnetiz.ai03

05Log it every week

One row a week, about five minutes. The number, the holdout's number, usage, whether it is past the line, and anything on the "what else" list that happened.

06Read it on day 30 against the signed rule

The rule was written before anyone knew the result, so the readout applies it and does not reopen it.

On day 30 the log showsDecision
Past the line, and the holdout is notKeep. Pick the next number
Past the line, but the holdout moved tooHold. 30 more days, a cleaner comparison
Not past the line, usage highFix. One change to what it does
Not past the line, usage lowFix adoption, or kill
Moved the wrong wayKill or roll back
Below the minimum countKeep recording. Decide nothing yet

07Record the decision and start the next charter

Both owners sign the readout. A kept tool names the next number it should move, because one moved number earns the next test, never a pass for life.

The terms, as this kit uses them

  • The number. The one result the rollout exists to move.
  • Baseline. The four weeks before launch, read the same way.
  • The line. The level past the baseline's swing that counts as moved.
  • Holdout. A group doing the same work without the tool for the same 30 days.
  • Minimum count. Below it the read is too thin, and nothing is decided.
