The method

How It Works

Seven steps. The runnable versions ship as the markdown files in this kit.

01Gate the spend

Enrich only records something downstream will use, capped per day. Records that miss the gate queue rather than burn, the queue drains inside the cap, and queued records expire and re-qualify, because the reason a record qualified goes stale too.

02Research with citations

Public sources, every claim carrying where it came from. Unknown stays unknown, never guessed. A cited claim audits in one click; an uncited claim is a rumor in a database.

03Date every fact

Every fact carries its date. A title verified last week beats one scraped last year, stale evidence is suppressed visibly rather than dropped silently, and a pre-existing value with no date is challengeable, because undated data lies.

Watch for the field that is confidently wrong. Undated data does not age, it lies.

04Propose, never overwrite

Silent overwrites are how trust dies. The agent produces proposed changes. Old value, new value, source, side by side, with conflicts and unknowns on the same screen and suppressed proposals collapsed beneath them. A rule that says never silently resolved needs a place on the screen. The record has not moved yet.

magnetiz.ai03

05Review the changes

A named person drains the queue on a cadence, and approval takes seconds because the preview did the work. Approve-all covers high confidence only. A field class graduates to auto-apply only when an approval streak AND a passing golden-records score both hold, because agreement is not correctness. Owner, stage, amounts, and human prose never graduate.

06Keep it reversible

Every applied change is logged with its prior state. Undo restores only when the current value still equals what the change wrote; a later human edit turns the undo into a conflict for a person, never a clobber. An enrichment pipeline you cannot undo is a pipeline you will eventually fear.

07Evaluate on golden records

The eval is the difference between an agent you tested once and an agent you can keep trusting. Five accounts you know cold, scored against a pass bar you wrote down first: correct minus five times wrong minus five times hallucinated, over findable fields. Re-scored when the prompt, model, or sources change, and the set grows from your rejections, because failures point at the fixtures you need.
