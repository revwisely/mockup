The method

How It Works

Seven steps. The runnable versions ship as the markdown files in this kit.

01Write the account rules before the list

The trigger is a named list of companies you intend to contact. Before anyone builds it, write the class test a stranger could apply to one company. Country, ownership, headcount band, the automatic exclusions, and the suppression lists. The agent can only be as precise as these rules.

02An agent checks every company

Two passes. A fast screen cuts the obvious rows from the name and domain. A research pass checks each remaining company on the web and returns KEEP, CUT, or UNSURE, with a source and a reason on every row. A missing source is UNSURE, never KEEP.

Watch for the domain trap. LinkedIn matches company lists on the website domain, so a subsidiary listed under its parent's domain pulls in the parent's whole workforce. The matched count looks healthy while the ads reach the wrong people.

03A person reads the cuts, then uploads

Every CUT reason and every UNSURE row gets a human read, plus a spot-check of a few KEEPs. The upload is a person's decision. If the list comes back small, loosen the campaign's job filters. Never re-add companies the check cut.

04Check the audience size before you design the campaign

LinkedIn will not serve a matched audience under 300 members. Read the matched count about two days after upload, then build only the layers you can fill today.

Watch for the layer that never activates. It sits in the campaign doing nothing, and nobody notices for weeks.

05An agent checks the campaign before launch

The builder reads what they meant to set. The agent gets the settings worksheet and the campaign as configured, from the API, an export, or screenshots, and lists every difference. Anything it cannot see is CANNOT SEE, never an assumed default.

Watch for a cost per thousand far below normal in the first days. Cheap impressions usually mean the ads left LinkedIn's feed.

06Ads first, outreach second

The account enters the audience and the ads run for about a week before the first message goes out. Ads introduce, outreach asks. Suppression runs both ways, so a reply, a meeting, or a new deal takes the account out of both.

07An agent writes the readout, a person decides

The gates are written before launch, each with the number, the day it is read, and the action under each outcome. Weekly, the agent fills in the readout from the exports. A person decides to continue, change, or stop, and writes one line of reason.
